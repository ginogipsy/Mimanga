# GINOGIPSY OS -> MIMANGA

## :: RETRO-COMPUTING SOCIAL HUB FOR UNFILTERED MEDIA CRITIQUE ::

Benvenuti in Ginogipsy, una piattaforma underground e open-source per catalogare, recensire e discutere di media (Manga, Film, Serie TV, Videogiochi) con un approccio senza censure, gestito tramite un'interfaccia a riga di comando (CLI) in stile anni '80.

### 🚀 Filosofia del Progetto

Ginogipsy nasce come un "safe space" digitale per la critica autentica e non filtrata.

* **UI/UX CLI (Command Line Interface):** L'interfaccia utente è interamente basata su comandi testuali (stile MS-DOS / Terminale UNIX) e animazioni ASCII in verde fosforo, per un'esperienza nostalgica e indie.
* **Contenuti 18+**: Le recensioni sono esplicite e senza censura. Gli utenti devono confermare la maggiore età per accedere al contenuto completo della bacheca.
* **Trust-Based Ranking:** Non ci sono commenti diretti alle recensioni per evitare flame war. Valutiamo solo l'affidabilità del recensore tramite un sistema di ranking interno.

### 🛠️ Stack Tecnologico

Il progetto è sviluppato interamente per l'ecosistema mobile Android, utilizzando le tecnologie moderne di Google con un look and feel vintage.

* **Linguaggio:** Kotlin
* **Interfaccia Utente:** Jetpack Compose (per una UI dichiarativa e reattiva)
* **Backend:** Spring Boot (per la gestione API e database centrale)
* **Database:** (Scegli tra Firebase, Supabase, o PostgreSQL)
* **Dati Media:** API di terze parti (es. TMDB, AniList)

### 💡 Funzionalità Principali

* **Comandi Interattivi:** Interagisci con l'app tramite comandi come view manga berserk, list games, help.
* **Bacheca Unica:** Ogni recensione è un post "stand-alone", senza thread di commenti.
* **Trust Score:** Gli utenti valutano i recensori, non le singole recensioni, creando una gerarchia di critici affidabili nella community.
* **Espansione Topic:** La piattaforma è progettata per espandersi facilmente in nuovi argomenti.
